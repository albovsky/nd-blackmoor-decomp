## How to read the denominators

- Code units are address bands of the indexed function spans (16 KiB bands within each code region), a stand-in for translation units until a unit map exists. Data units are image pieces from layout.json.
- Baseline code totals are function spans (start to next indexed start). A span also holds the function's switch jump tables and `int 3` padding (about 10.9 KB in all, M0 report section 3), so baseline code is slightly overstated and baseline data slightly understated until the M02 ledger splits them.
- M03 tables and padding are excluded from matched code; their data items are handed to M02. Baseline mode does not ingest composer data evidence; use a ledger to count structured/reconstructed data.
- Referenced (not yet reconstructed) ranges are reported as not done, never as matched.

Byte evidence was **not** re-verified in this run (legacy manifests trusted; pass --verify-original to re-verify them; M03 audits are prior evidence with current source hashes checked).
