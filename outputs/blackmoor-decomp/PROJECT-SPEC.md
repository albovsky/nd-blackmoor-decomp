# Blackmoor source reconstruction requirements

The final result must include buildable reconstructed game source, a reproducible whole-file rebuild matching the supplied GAME.EXE bytes, and a native ARM64 macOS app playable through both difficulty modes. The executable SHA-256 is `afd337a2468e0cd540f487db2c121ccb9ccb9757836578c15d2d8a52f3485c45` (1,511,424 bytes). Current verified coverage is 126 unique exact bytes: six complete accessor extents (112 bytes) from explicit mnemonic assembly, plus two incomplete 7-byte ranges. This does not prove original C/compiler provenance or a whole-file rebuild. See CURRENT-INTEGRATION.md for the pinned snapshot.

The owner's GOG installation remains the source of executable/data assets. The native app may use platform and codec adapters but may not use ScummVM, Wine or a VM as its game engine. Native behavior must preserve recovered action ordering, dependency gates, phase/completion semantics, scene changes, time, inventory, dialogue, puzzles and saves. Unsupported paths must be explicit rather than silently skipped or synthesized. Source reconstruction, host-adapter validation, original-code oracle validation and whole-file byte matching are different evidence classes.

Workers use GPT-6 Luna Max. Each independent worker owns separate new module, test, build and evidence files. Shared parser, dispatcher, platform and app changes are integrated by one owner to avoid concurrent edits. Original files are read-only. Keep private binary/resource evidence local and out of the distributable investigation archive.

The current machine is an M1 Pro running macOS27.0.1 with Xcode27. The current FFmpeg build sets a macOS27 deployment floor and remains an external Homebrew dependency. Do not describe the bundle as portable to older macOS releases or independent of those libraries. UI/hardware audio verification waits for the owner's explicit unlock; automated/offline tests can continue.

Completion requires reproducible builds and exact complete-executable comparison, successful fresh-game/save/load/endgame behavior, both difficulty playthroughs and targeted regression checks for every reconstructed branch. A slice may finish with its own bounded evidence; it cannot mark the game complete. The current slice proves selected S0 BOOT, caption, audio and hotspot boundaries and loading S5900's first frame. It does not prove live scene execution, original decoder equivalence, complete initialization, caption rendering, timed video or full gameplay.
