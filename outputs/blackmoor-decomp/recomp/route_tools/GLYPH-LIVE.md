# First-time Junior glyph input client

`glyph_live.py` makes one bounded attempt from a genuine pending m28 at
S3510/view4/held-1. It rejects Senior/repeat sources before opening the board.
The original game owns all swaps, scoring, timers, win, reward and saves.

```sh
python3 glyph_live.py --native "$NATIVE" --native-sha256 "$NATIVE_SHA256" --game-exe "$GAME_EXE" --game-data "$CLEAN_DATA" --source-save "$M28" --save-sha256 "$M28_SHA256" --atlas "$LOCAL_ATLAS" --atlas-sha256 "$ATLAS_SHA256" --save-name m29 --output "$NEW_EVIDENCE_DIR"
```

Use Python3.11+ and macOS/APFS clone support. Native/source/atlas pins and the
original data-image pin are required. The clean data seed has no Documents5
saves or symlinks. All supplied files remain read-only inputs; producer and
reload run in separate fresh clones. Existing output is never overwritten.
Default output is a new retained scratch directory.

The caller-owned JSON atlas has exactly25 SHA256 keys in `tile_hashes`.
Reference/source-path metadata is ignored. No atlas, asset, image template or
resource payload is bundled, generated or committed by this tool. Every35-cell
capture must match the provided atlas; unknown/animated crops settle only
within the bounded existing policy, then refuse. The preserved private pixel
heuristic selects ordinary UI events, not guest state; its score estimate is
not win proof. No new solver, score/refill model, RNG access or repeat mode is
provided.250ms holds/500ms endpoint spacing/200ms swap gap and the proven
reward/Bye/inventory/save input timing are preserved.

The full-scope result requires original1299 open and actual2001,1294/1295
continuation, original pickup at1945 with1357=1 and1418 cleared, actual held4,
PUT/X, safe original UI save and two final safe producer observations.1945 is
a scene, not a flag. Clocks are valid monotone diagnostics with the observed
source gate; the whole run is not restricted to the request leg's afternoon
window. Source/board1418 stays1 until pickup.

A second fresh clone launches with only the new UI output, selects actual4
at134,243, puts it away and closes inventory. The proven reload prefix is
retained with an explicit center73000/shot76000 two-token final-pair delta.
Source/copied/output/native/tool/atlas/request/capture/log hashes and complete
FIFO finish/normal exit are required. Engine-generated continue-save files
may remain as evidence, but the tool never chooses them as canonical input.
Only the combined outer receipt sets accepted=true. A late copy/hash failure
may leave a file in refused evidence; it remains an unaccepted checkpoint.

Limits: one game,48attempts,64requests including finish,180seconds/session,
512steps/64KiB per batch,90M imports/1.8M idle polls. Natural loss, unknown
board, deadline, incomplete input, missing win/reward/actual4 or failed reload
returns1 and retains refused evidence. There is no automatic retry, all-board
or platform-timing guarantee. Private runtime captures/data must not be
published. Root collection passed the final public m28 full-scope producer and fresh
reload on native74229ec8 (RECOMP-19). That bounded run does not establish
all-board success or repeat/Senior support.
