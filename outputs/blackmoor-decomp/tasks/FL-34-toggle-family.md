## Rulings (root, from the coordinator and AGENTS.md)

- A function with an unreachable block behind an always-true guard stays pending: drop it and write the disassembly reason in the handoff.
- A function where only some jump directions can never be taken but every instruction runs may be credited; flag each such edge in the handoff and in the differential's allowlist with a reason. (None expected: these shapes have all edges takeable.)
- Library rows never count. A receipt blocker clears only via `blockers_reviewed` with a 40+ character reason (none expected).
- Over about 25 tool calls per function: drop it back to the pool with a written reason. Same-shape rows after the first of a batch should cost far fewer.
- Callees, vtable entries, renderer, sound, text, scene layer and Win32 imports through IAT slots: host stubs that pop their arguments and return scripted `eax`. `0x4c5377` is thiscall with 4 stack arguments (read its first `ret` for the pop count); `0x40236a` and `0x404be1` are thiscall with no arguments, as in FL-32a.
