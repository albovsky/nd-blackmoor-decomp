# A-28.3.2: Sequence timing and completion loop

Parent: A-28.3. Recover `0x44753b` frame count, curve, pump, pause, restart swap and final state changes. Keep this child open until the native callback, timing, event-pump and integration boundaries are implemented and tested.

Status: original contract recovered; full native playback remains open.

After the first blend at weight 1.0, the controller measures one `GetTickCount` interval. If it is zero, it selects 30 frames. Otherwise, if signed 32-bit `elapsed * 2 < sequence_budget_ms`, the configured count is signed integer `sequence_budget_ms / elapsed`; otherwise it selects two. The loop is a do/while, so it still performs one frame if signed wrap/division produces a configured count below one. Native `action_family28_sequence_frame_count` matches eight original scripted-tick traces, including positive DWORD wrap and a negative signed delta.

For each later frame `j`, with `N` the selected count, the original weight is `1 - exp(-((j - N*1.3)^4) / ((N*1.5)^4 / 8))`. The original calls the blend routine, then the engine event pump once per frame. Subtypes 1 and 3 also poll `GetTickCount` until `pause_ms` expires, pumping events during the wait; subtype 2 skips this pause. The real event pump at `0x4f52a9` processes DirectSound events and is not run by the isolated oracle.

At completion subtype 3 swaps the two capture-buffer pointers, resets the scene state from 4 to 1, and returns to stage 1 while keeping `busy` and the render guard set. Subtypes 1 and 2 clear `busy` and the render guard and set the redraw flag. The sequence oracle records these transitions but skips the `0x4477d1` frame write and `0x4f52a9` audio/event pump at their entry boundaries.

The exact ambient x87 precision at the effect call is unresolved. The source exposes both observed LUT modes, 0x027f and 0x037f, but it does not claim that the sequence `exp` or live frame output matches a chosen production policy. Full sequence rendering stays blocked pending an explicit caller policy and host capture/pump/presentation integration.
