# A-28.3.2: Sequence timing and completion loop

Parent: A-28.3. Recover the `0x44753b` sequence loop with original-derived timing, curve, pump, pause, buffer swap and final state changes. This child implements the portable synchronous controller and keeps live host rendering/pump integration separately scoped.

Status: controller source and callback contract implemented; original chained capture/blend geometry independently confirmed. Ambient x87 policy, Windows CRT `exp` parity, and live platform callbacks remain open integration limits.

## Recovered geometry and call order

The original `0x446ffb` initializer sets object `+0x39 = width*height`, `+0x3d = width`, `+0x41 = height`, and `+0x45 = width*source-bytes-per-pixel`. It allocates both `+0x31` and `+0x35` capture buffers at `+0x39*12` bytes. `0x447ac7` captures the full canvas into three little-endian DWORD channel words per pixel, with `+0x3d` as the pixel stride. The effect rectangle is the inclusive object rectangle at `+0x1d..+0x29`; body-loaded crop offsets at `+0x4e/+0x52` are independent of that target rectangle.

An original chained fixture exercised a 4×3 full canvas, 144-byte captures, nonzero effect rectangle `(1,0)-(2,1)`, and crop origin `(1,0)`. Original setup/capture spans matched the native full-canvas representation; original `0x4477d1` output matched the native adapter and left outside pixels unchanged. The integration evidence test `tests/test_action_family28_frame_oracle.py::test_original_initializer_capture_crop_and_blend_tuple` is pinned at SHA-256 `8c3d0b330e5fbf3cabc68b786a119dc8f4c4bd5c84b2cbbe69a64e55879de3c0`. Its original byte windows are `0x446ffb..0x447166` (`cc4db654f3be4ff4a547245ae96732692a9dc174fa743a71cf505b35f14d651a`), `0x4471ca..0x44727a` (`8b0f82614a0e63fc5a928bd26bd1711cdc038eed361aaaa96fb9d11cb3dda307`), `0x44727a..0x4473a9` (`6caf49a8c027e1f717eb5dcd68244dbe0cc4ebccd437f6c8163097eacb1a969d`), `0x447ac7..0x447c1c` (`3a19f5c7853668313271d3d46a361add8876f23c1cf9d6e1ee3a15167cee116f`), and `0x4477d1..0x447ac7` (`be28d4a5f9c6e9c5273ac3ab8a1a0bf326230e34d15e67e9d81d13ec64b4d182`) in the pinned executable `afd337a2468e0cd540f487db2c121ccb9ccb9757836578c15d2d8a52f3485c45`. The controller unit suite separately checks full-span bounds and independent offsets.

`0x44753b` calls `GetTickCount`, renders frame zero at weight 1.0, samples the tick again, then computes the wrapped DWORD elapsed value and selects the frame count. A zero elapsed interval selects 30. Otherwise, signed 32-bit `elapsed*2 < sequence_budget_ms` chooses signed integer division `sequence_budget_ms/elapsed`; the other branch chooses two. The original loop is a do/while, so a selected count below one still executes its first iteration. Later frames call the blend boundary then the system/audio pump once each. Subtypes 1 and 3 also poll ticks and pump while their pause duration has not elapsed; subtype 2 skips the pause.

At successful completion subtype 3 swaps the capture pointers, resets scene state from 4 to 1, and returns to stage 1 while keeping `busy` and the render guard set. Subtypes 1 and 2 clear `busy` and the guard, set redraw, and perform the original finalizer writes. Mutations and callback effects follow source order. A nonzero callback result stops immediately and reports the completed prefix; the controller does not synthesize cleanup or retry.

## Native contract and evidence

`action_family28_run_sequence` injects synchronous tick, full `0x4477d1` blend/present/graphics-tail, and `0x4f52a9` system/audio-pump callbacks. The frame callback receives explicit x87 control word, target rectangle, full immutable captures, dimensions/stride/crop offsets, and primary-target state. It intentionally receives no final frame count because frame zero precedes the second tick. Production callers must select an explicit supported CW (`0x027f` or `0x037f`); the game's ambient precision-control policy is unresolved.

The original oracle compares the native callback order and controller state transitions exactly for the scripted cases, including zero elapsed, signed/wrapped timing, pause variants, and callback failure. Curve results are reported separately with no ULP tolerance and no exact-parity claim. For counts 2 through 64 (2,079 weights per CW), CW `0x027f` has 1,310 exact weights, 769 differing weights, maximum 46 ULP; CW `0x037f` has 1,066 exact weights, 1,013 differing weights, maximum 46 ULP. The sweep does not isolate the remaining drift to native `exp`/libm; exact Windows CRT `exp` and full instruction-evaluation parity remain unresolved. A quotient-normalization defect found in review was corrected and is covered by exact significand/exponent tests for 1/3 at both x87 precisions, plus the reachable frame-3/count-5 curve sample. In the same sweep, each original/native weight pair produced identical native LUTs across all 4,096 channel pairs, and the fixed seeded 3×2 packed sample had no changed pixels. This is impact evidence for those cases, not full-frame or visual parity; the original LUT itself was compared exactly for 24 sampled weights per CW.

Focused validation currently covers 12 controller tests. The bounded original oracle also covers 72 constructors, 92 dispatcher cases, 196,608 LUT entries, 288 visible packed pixels, and scripted controller traces. See `work/analysis/slices/A-28.3.2-sequence-oracle.json` for the pinned executable hash and per-check evidence.

## Remaining limits

This controller invokes callbacks; the scripted harness records them instead of performing real framebuffer capture, DirectDraw/host presentation, graphics-tail pumping, or DirectSound/system event pumping. The original chained geometry fixture proves the 16-bit in-memory capture path, not DirectDraw locking. Exact Windows CRT `exp` output, attribution of remaining curve drift between `exp` and other evaluation differences, and the application’s ambient x87 policy remain unresolved. Curve weight drift is bounded for the tested count/frame domain but remains nonzero; no full-frame equivalence is claimed. Nonempty recursive dependency reset and allocator-failure dialog behavior also remain outside this child.
