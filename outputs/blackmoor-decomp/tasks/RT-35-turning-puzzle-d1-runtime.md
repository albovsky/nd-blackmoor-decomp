Owner thread: Claude Sonnet (cloud). ## The original (GAME.EXE, SHA-256 afd337a2...5c45)

Recovered by this slice (Ghidra pseudocode is navigation; the numbers below were checked in the x86 and the oracle re-checks them):

* Dispatcher `0x427a50` arm `0xd1` at `0x42a175`: gate `0x423f57(deps, 0)` (ECX `0x63786d`), then `0x4b64a9(ECX = 0x61d449, row)`. No `0x42ba3a` in the arm. The object (CTurningPuzzle, `0x278` bytes) is a static singleton.
* Loader `0x4b5c5c` (A-D1.1, `src/action_family_d1.[ch]`): 927-byte typed body, no dependency interplay. Body layout in `src/action_family_d1_runtime.h`.
* Handler `0x4b64a9`, a switch on the row phase (`0x5bb632 + row * 0x8d`):
  * **phase 0** (`0x4b64f9`): row, active, `[0x5bb1ca] := 1`, `0x4e8d96`, four dword zero stores at `+0x254`, per tile (N = word `+0x21`) the destination rectangle (body `+0x47 + 16 i` plus the view origin `0x583186` / `0x58318a`), the initial frame and the source rectangle from `0x4b6355`; `+0x224 := 1`; generic Z entry (`0x4d39f9`, type 10, callback `0x4b7051`, label "TURNING PUZZLE OVERLAYS"); the image through `0x4c2790("CIFTREE", name, 6, "Turning Puzzle Surface")` only if `+0x20 == 0`; `0x4fb77a` for each sound record whose name is not "NO SOUND" (9-byte compare); `+0x22a := 0`, `+0x229 := 0`, `+0x22c := 1`, state `+0x274 := 0`, phase := 1.
  * **phase 1**: a six-state machine on `+0x274`: 0 idle (`0x4b642d` solved check, or 4 once solved), 1 start (win-sound branch, `0x4f6334` busy test), 2 animate (per tile frame advance, geometry `0x4b6355`, `GetTickCount` deadline `T * 1000 / S`), 3 wait for the deadline, 4 auto-turn (deadline `T * 8000 / S`, counter byte `+0x22b`), 5 wait for the win sound.
  * **phase 2** (`0x4b6dee`): `[0x5bb1ca] := 1`, `0x4fba69` for record 0, the win block (body `+0x32a`, applied when solved and not exited) or the exit block (`+0x376`): scene change cells plus start flag plus engine mode 4 unless the scene word is 9999, event flag store unless the index is -1; then `0x42ba3a(row)` and the cleanup `0x4b5bc8`.
* Pointer receiver `0x4b5d17(x, y)` (cascade `0x4f0059` at `0x4f0b1e`, x = `[ptr+0x5e]`, y = `[ptr+0x5a]`) recomputes every source rectangle and hit-tests the tile and exit rectangles; `0x4b6097` writes the cursor index, `[0x5c39e5]` (0x276c tile / 0x276d exit) and `+0x252`.
* Click `0x4b617a` (accepted-release chain, `0x43b287`): acts on the retained `[0x5c39e5]` only while active, unsolved, state 0 and the row phase is 1.
* `0x4b5c11` slot invalidate (`0x43d91f`), `0x4b5bc8` / `0x4b5b8a` cleanup (`0x438b76`, `0x43de6b`), render callback `0x4b7051`: one `0x4c5377` opaque blit per tile.
