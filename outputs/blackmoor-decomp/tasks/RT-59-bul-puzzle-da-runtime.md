## The original (from the Ghidra pseudocode; verify in the disassembly)

The object is one 0x1b9-byte singleton at `0x624734` (ECX for every method; allocated by `0x45b300`, constructor `0x45b37a` -> reset `0x45b3ea`). The loader `0x45b4ae` (dispatcher loader arm `0x41061d`) copies the 2,958-byte body (decoder `src/action_family_da.[ch]`, already merged). The body pointer of a row is `[0x5bb5e5 + row * 0x8d]`, the row phase dword is `[0x5bb632 + row * 0x8d]`.

| address | role |
|---|---|
| `0x45c18f` | handler, dispatcher arm `0x42a424` after gate `0x423f57(deps, 0)`, `ret 4` (row word) |
| `0x45b5bb` | pointer receiver (`ret 8`, x = [event+0x5e], y = [event+0x5a]); called at `0x4f0c63` in the cascade `0x4f0059`, a hit returns 1 and calls `0x45b7a8` (candidate writer, cursor cells) |
| `0x45b872` | click on an accepted release, called at `0x43b2f5` in the chain `0x43b2a0`; acts on the retained candidate `[0x5c39e5]` (0x27ba = a button, 0x27bb = the pass / pick) |
| `0x45b477` | slot invalidate (`0x43d9ba`) |
| `0x45b42e` | cleanup (`0x438bfd`, `0x43ded9`, and the end of the handler): releases the surface (`0x4c2dfb`) and slot (`0x4d3992`), then reset `0x45b3ea` |
| `0x45d2c6` | render callback of the generic z entry (type 10), reads the object through globals, uses `0x45b568` (rect + view origin) and the blits `0x4c5377` (restore) / `0x4c5d4b` (draw) |

Pure data movement on the object and the body is the kernel's.
