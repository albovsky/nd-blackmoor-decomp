# RT-52: raw 0xaa Alarm Clock runtime

Owner thread: Claude Sonnet (cloud). Follows RT-50 (PR 115). Ranking from `scene-action-coverage.json` after PR 115 (0xe0 and 0xd6 are RT-51's): the families left that unblock two scenes (0x1c, 0xd3, 0xe4, 0xeb, 0xf5) all have 7,000+ byte closures or, for 0x1c, parse a file through the C runtime and drive an external player object (`0x637fcf`). Raw 0xaa unblocks one scene (the only scene with a 0xaa row, resource 1535) and is the smallest self-contained family left: one singleton object `CAlarmClock` at 0x624cbf, handler `0x44da08` (1,565 bytes) plus pointer `0x44d28c`/`0x44d597`, click `0x44d624`, render `0x44e035`/`0x44d9b5`, time helpers `0x44d711`/`0x44d8ad`/`0x44d946`, invalidate `0x44d19d`, cleanup `0x44d154`/`0x44d107` (about 5,300 bytes in all). Raw 0xaa is the "Alarm Clock": a clock face that shows the game time (time mode), lets the player step an alarm hour with increase/decrease buttons (alarm mode), set it, or cancel.

The contract is `src/action_family_aa_runtime.h`, the kernel is `src/action_family_aa_runtime.c` (both written first, from the disassembly). The shape is the 0xd0 family (`action_family_d0_runtime.[ch]`, `session_bindings_ad0.[ch]`, `tests/action_family_d0_*`). GAME.EXE SHA-256 afd337a2...5c45; private evidence is `work/original/GAME.EXE` (extracted from `/mnt/project-files/private-inputs/work-private.tar.gz`); disassembly helper `work/rt52/pe.py` (`python3 pe.py <hex va> <len>`), scratch disassembly of the handler in `work/rt52/aa_handler.txt`.

Handler phases (row phase dword 0x5bb632 + row * 0x8d): phase 0 = `phase0` in the kernel (order: row, active, 0x44d711, dirty, 0x5bb1ca := 1, restore/state/over := 0, slot alloc and entry stores, surface load only if +0x20 == 0 (unconditional, no empty-name test), entry surface, sound prepare of body+0x265 unless "NO SOUND", set/canceled := 0, row phase 1); phase 1 jump table at 0x44e001 (states 0..8, above 8 nothing); phase 2 (0x5bb1ca := 1, stop body+0x265 unless "NO SOUND", canceled -> cancel block, else set -> 0x44d946 then set block; then `0x42ba3a(row word)` and the cleanup). Any other phase does nothing. The kernel header and source carry every detail; where this packet and the disassembly disagree the disassembly wins and the packet gets fixed.

Native-only refusals (the oracle must not run them against the original; test them natively): body validation (`alc_validate_body`: short body, name or sound names without NUL), phase 1/2 without phase 0 for the row, event flag index outside the host window in phase 2, render with an hour index outside 0..11 or a quarter outside 0..3 (the original indexes past the body), render with the slot -1.
