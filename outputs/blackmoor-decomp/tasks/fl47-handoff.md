## What changed in the method

1. `scripts/fl43_equiv.py`: new facts `holds` (a register holds the 32 bits at `[base + disp]`, from a store or a load) and `eq` (two registers hold the same value: a copy, or two loads of the same frame slot / absolute address), a repeat load that changes nothing ends no fact, and an **exposed-frame mode** (`exposed_ok`): `lea r, [ebp - d]` no longer refuses the function; slots at or above the lowest such address can change in a call, a string instruction or a store through a pointer, and a store into them ends the pointer-based facts; slots below it keep their facts. `tests/test_fl47_equiv.py` checks every fact against the original run under Unicorn (38k facts at 40 seeds) and holds two unit proofs.
2. `scripts/fl41_survivors.py`: `signed_narrow_ok` (a narrow compare of a slot that holds a sign-extended 8/16-bit value, against a non-negative immediate, before an unsigned or equality jump), `logic_jump_ok` (a neighbouring condition after `test/and/or/xor`, which clear CF and OF), and `strlen_nonneg` (SF is 0 after the string-length idiom `or ecx,-1; repne scasb; not ecx; add ecx,-1; test ecx,ecx`, because the 2 GiB address space bounds the scan). The survivors script passes `exposed_ok=True` to the prover.
3. `scripts/fl45_targeted.py`: alias scenarios (an earlier store through a register is made to hit the cell a later reload reads, one or two input cells), conditional jumps try the input cells one at a time, and operand values with a bit above a narrower width set.
4. Sonnet diff review (code only): one P1 (a store into an exposed frame slot must end `holds` facts: fixed) and one P2 (a budget kill needs the unmutated port to agree with the original: fixed); the budget rerun and the survivors classification were redone after the fixes.
