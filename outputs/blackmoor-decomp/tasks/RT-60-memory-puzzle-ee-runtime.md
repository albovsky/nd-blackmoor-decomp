The body byte `+0x346` is written (:= 0) by the original when there is one page; the kernel never writes the body, so the oracle compares the body with that one byte excepted. The original frees the cell array and id table in the clear; the kernel keeps their bytes, so the oracle compares the cell and id bytes only while the object's pointers are nonzero.
