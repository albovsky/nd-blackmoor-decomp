# Build icon and software cursor implementation plan

> Execute under the existing AGENTS.md delegation and independent-review workflow; root owns shared build/platform/app integration and publication. No further permission is required for the already-requested merge.

**Goal:** Future native builds carry the owned game icon, and the recompiled game does not show the macOS cursor over its framebuffer cursor.
**Architecture:** Extract icon group 128/language1033 from the hash-pinned owner GAME.EXE at build time; convert to an ICNS in bundle Resources and name it in Info.plist before signing. The platform has an opt-in software-cursor mode using an AppKit transparent cursor rectangle limited to the visible rendered surface; the recompiled frontend opts in. Other platform clients keep their existing cursor behavior.
**Spec:** User request in the authorizing Codex chat: make the icon part of the build and merge; report/fix overlapping macOS/game cursors. AGENTS.md and PROJECT-SPEC.md constrain original data and testing.

## Task 2: Cursor integration

- Root owns src/macos_platform.h, src/macos_platform.mm, recomp/macos_recomp.mm and a bounded new cursor fixture/test wrapper.
- Add an opt-in platform API. Only the recompiled frontend enables it. Keep the system cursor visible until a software-rendered frame is present. Register a transparent NSCursor only for intersection(rendered surface, visibleRect). Do not use global hide/unhide counters. Let AppKit own enter/exit and focus handling.
- Invalidate cursor rectangles when opt-in state, first frame, fit/stretch mode or relevant geometry changes, and on stop/close. Preserve bars/title/menu/outside-app cursor behavior.
- Add a hidden synthetic fixture that observes actual cursor rectangle registration and transparent image pixels without setting/hiding the real pointer, moving the mouse, making windows key/visible or changing owner preferences. Verify default/off, enabled-before-frame, fit/wide/narrow/stretch, clipping, resize/mode update and stop. Observe baseline red and candidate green.

## Review focus

1. Original icon selection/language and missing/truncated/corrupt resources produce a clear build failure; wrong executable hash rejected before resource conversion.
2. All output ICNS sizes decode and the plist/resource is covered by the final signature; assets stay untracked.
3. Software cursor opt-in affects only the game surface with a frame, not letterbox bars/window controls/other native clients.
4. Resize, fit/stretch, clipping, stop/reopen and loss of foreground cannot leave the system cursor suppressed globally.
5. Frozen source/build hashes, test receipts, remaining conditional skips and unverified physical/foreground behavior are reported accurately.
