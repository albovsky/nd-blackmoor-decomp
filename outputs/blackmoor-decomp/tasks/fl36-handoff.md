A callee that changes `self` or a global the function reads again is not exercised (none of the functions reads anything again).
- `newctor` and `ctoreh`: the structured-exception frame (`push -1; push handler; fs:[0]` chain, the state variable) is not modelled, as in FL-27c and FL-28a; the handler runs only when a callee throws. The oracle does run the frame and checks that fs:[0] is restored.
- `newctor` takes no `this` and passes the pointer returned by 0x51dc43 (a 32-bit original value) to the constructor callee as `this_ptr`.
- Getters, setters and the `dtor`, `ctor` families treat `self` as raw bytes at the original offsets and do no bounds checking, as in the original. `getf`/`setfa`/`setfi` offsets go up to 0x8256; the test objects are sized to the largest offset.
- `0x4144c0` (`newctor`, ledger class `partial_native`) carried one receipt blocker (`A-1B.1:852ed72cb0abacd9`, an unverified-branches item about the runtime wiring of owner init/free 0x4144c0). It is cleared with a `blockers_reviewed` rationale: this port is the pure allocate-and-construct function, proven against the original bytes; the wiring stays with the integration. Glib can overturn.
- Nothing in the macOS glue was built or run and no kernel calls these symbols yet.
