# A-28.3.1: Render gate and surface capture

Parent: A-28.3. Recover `0x447c36` dispatch eligibility and `0x447ac7` 16-bit-to-normalized-RGB capture. This child does not implement DirectDraw locking or live presentation.

Status: implemented, original/native compared, and peer-reviewed; this child covers the pure gate/capture helpers only.

The outer gate is true exactly when the effect is busy and either subtype 1 runs in scene state 4, or subtype 2/3 runs in state 4 at stage 0 or state 3 at stage 1/2. The oracle covers 36 combinations; nine enter the controller, and the native predicate matches all cases.

Capture walks the requested rectangle by row pitch and emits the three original channel values `(pixel >> shift[channel]) & mask[channel]`. The bounded helper validates rectangle, pitch, source/output capacities, pointer-span overflow and non-overlap before writing. Native output matches actual original `0x447ac7` on a 4x2 surface and a 2x2 crop from a four-pixel row pitch.

Oracle evidence is in `work/analysis/slices/A-28-original-oracle.json`. The source capture used the internal-memory surface path; DirectDraw lock/unlock error behavior remains outside this child.
