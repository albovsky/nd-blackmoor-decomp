Known wrinkles preserved in the kernel (do not "fix"): the cursor is a '-' appended to the field text, so a typed '-' that is the last character is removed with the cursor; Backspace removes the cursor first and then one more character; the second-field loop of state 1 sets wrong / state 2 on the first miss even when a later accepted word hits (a later hit still stores correct and state 5, and the wrong flag stays, so the finish uses the wrong block); an empty accepted word matches every text (strstr with an empty needle); the cancel strip is not shifted by the view origin; the click does not look at the row phase; the finish releases the font that the scene cleanup (`0x43dbe3`) never releases.

Native-only refusals (the oracle must not run them against the original; test them natively): body validation (`pwd_validate_body`), phase 1 or 2 without phase 0 for the row, an event flag index the host refuses, a host failure after effects.
