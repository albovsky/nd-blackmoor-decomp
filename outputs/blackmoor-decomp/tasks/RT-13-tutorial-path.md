# RT-13: make the tutorial (S0 -> S6400) respond: raw 0x79 runtime, then the next stops

Root (Claude Code) assigns this to a Sonnet (high) `slice-implementer`; one independent `slice-reviewer` afterwards. Base: current `main`. **Owner bug report (Glib, 2026-10-14, real window):** New Game works and reaches the tutorial, but nothing in the tutorial is clickable.

## Cause (confirmed from Glib's window log and a headless repro)

From S0 ("Player Challenge Screen") the click on hotspot row 32 enters S6400 (the tutorial). S6400 loads, draws and runs rows 0-14, then the scene session blocks at **row 15, raw type 0x79 ("Remove Inventory Item, No Hotspot", 2-byte typed body, no dependency)**, which has a parser layout (A-79.1, `src/action_family_79.[ch]`) but no runtime handler. A blocked session stops all later ticks, so the pointer events that keep arriving are ignored and nothing is clickable. Repro: `BlackmoorNative --inspect-live-session --live-click-row 32 --live-ticks 3000 --log <new path>` stops with `scene_session_blocked stage=3 provider=action-kernel action=15 type=0x79`.

The rest of S6400: rows 16-17 are raw 0x36 "static photo overlay - hot" (typed 280 and 1252-byte bodies, A-36.1 decoder merged; the static overlay loader/runtime family is `src/action_family_37.[ch]` and the A-37.2/A-37.3 notes in `work/analysis/slices/`), row 18 0x9f sound (bound), row 19 0x0a scene change (executor), row 20 0x97 (bound, RT-8). Rows 16-17 are almost certainly the clickable things in the tutorial.
